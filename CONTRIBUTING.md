# 🤝 Contributing

1. Fork the repository

2. Create feature branch (git checkout -b feature/amazing)

3. Commit changes (git commit -m 'feat: add amazing feature')

4. Push to branch (git push origin feature/amazing)

5. Open Pull Request

```text
feat: new feature
fix: bug fix
docs: documentation
test: tests
refactor: code change
style: formatting
chore: maintenance
```
